# GameEngine2D
What is this game engine:
This game engine is built for 2D games. Its coded in c# and supports c# scripting that can be attachted to gameobjects.
This game engine is very simple and is easy for scripting simple games. It does not *currently* support things like
large projects although u could kinda do that but the engine is not at that level yet

Information:
There are a few features with a list below. I plan on developing on the components, the UX and also things like Player cameras etc
